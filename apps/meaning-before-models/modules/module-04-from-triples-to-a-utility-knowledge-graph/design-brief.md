# Module 04 Design Brief: From Triples to a Utility Knowledge Graph

Status: approved for production under standing owner authorization

## Learning decision

The learner must decide which reviewed statements belong in a bounded utility graph and prove that
an answer follows an explicit path. A node-link picture is a view of the graph, not the graph itself.

## Experience architecture

This lesson is a relationship-discovery laboratory. It opens with source records sitting on separate
islands. The learner sees how reviewed identities allow statements to meet, distinguishes the
statement ledger from its visual projection, grows the graph by loading source packets, and tests
three competency questions. The final path defense forces the learner to name the statements,
sources, missing edge, and unsupported boundary.

The composition is intentionally different from Module 03's forensic evidence room and Module 05's
decision room. Source islands, route maps, an illuminated evidence path, and a graph-scope fence form
the visual grammar.

## Visual Arsenal selection

| Idea | Natural shape | Selected visual | Learner conclusion |
| --- | --- | --- | --- |
| Separate systems cannot answer a cross-domain question | islands | Source-island scene | Records can exist while the connecting path does not |
| Statements and pictures are different representations | comparison | Ledger-to-view split | The triples are the graph; the diagram is one view |
| Shared nodes create traversable routes | network growth | Shared-node route map | Reviewed identity lets separate statements connect |
| An answer needs an exact supporting path | illuminated path | Answer-path overlay | Every answer can point to the edges that support it |
| Graph scope must remain bounded | boundary map | Scope fence | More data is not automatically more useful knowledge |

## Signature mechanism

The Graph Growth Laboratory starts empty. The learner loads five reviewed source packets containing
thirty statements. Each statement remains visibly attributed to its source. Three utility questions
begin unanswerable and unlock only when all required packets are present. Removing one source breaks
the affected path without pretending the answer is false.

## Assessment design

The sequence is missing-edge multiple choice, graph-literacy flip cards, relationship matching,
the thirty-statement growth laboratory, a path tracer, a boundary multi-select, and the applied
Utility Mini-Graph. This sequence does not repeat Module 03's evidence-selection and identity-docket
pattern.

## Work product

The Utility Mini-Graph records one competency question, source groups, governed nodes, explicit
relationships, the answer path, a missing-edge test, source authority, and an unsupported-claim
boundary.

## Evidence boundary

All Riverbend records and answers are instructional. RDF defines graphs as sets of triples. RDF
datasets can contain a default graph and named graphs. Named graphs help organize and discuss graph
content, but do not by themselves prove truth, authority, governance, or permission.
