01
Incident clock

Two seconds, one outage, and several kinds of evidence

A wastewater overflow response agent must identify upstream lift stations, active work orders, recent telemetry, and the current emergency procedure within two seconds. The maintenance source is intermittently unavailable. Telemetry changes every few seconds. The procedure changes rarely but must remain version-controlled.

One access pattern cannot satisfy all of those obligations. The right question is not where should all data live. Ask what each source and workload requires.

02
Pattern field

Name the four patterns without ranking them

Virtualization queries governed data where it lives. A cache keeps a temporary reusable result or data subset. An index creates a retrieval structure, such as search or vector indexes, while authority remains elsewhere. Materialization writes a governed representation for repeated use.

Every cache, index, extract, replica, and materialized graph is a copy with freshness, security, lineage, deletion, recovery, and cost obligations. A hybrid architecture often uses several patterns by source.

    Questions people actually ask

    Does virtualization mean no integration work?

    No. It still needs connections, credentials, mappings, query planning, permissions, source availability, and performance controls.

    Is a cache authoritative?

    Usually the source remains authoritative. The cache needs a freshness and fallback policy for its allowed uses.

    Is a search or vector index a copy?

    Yes. It is a derived retrieval structure with lineage, security, refresh, retention, and deletion obligations.

    When should we materialize?

    When measured latency, resilience, transformation cost, reuse, or source limitations justify a governed copy and its lifecycle.

    Can one solution mix patterns?

    Yes. A question may virtualize current asset records, cache emergency reference data, index documents, and materialize a hot relationship path.

    What does move less data first mean?

    It is a prompt to avoid unnecessary replication. It is not an absolute rule that overrides reliability, latency, cost, or safety.

    Evidence boundary

    The access recommendations are instructional. Production choices require local workload measurements, source contracts, security review, resilience engineering, and cost analysis.

    Module Glossary

    virtualization

    Accessing governed data through mapped queries while the authoritative records remain in source systems.

    cache

    A temporary reusable result or bounded copy maintained under freshness and invalidation rules.

    index

    A derived retrieval structure that helps find source evidence.

    materialization

    A persisted representation created for repeated query or processing use.

    query pushdown

    Executing parts of a query in the source system rather than moving all source data.

    freshness

    How current evidence must be for a defined use.

    recovery objective

    A measurable target for restoring service or data after failure.
