# Evidence Boundaries

## What the evidence supports

- RDF represents graph statements using subject, predicate, and object triples.
- SPARQL queries RDF graph patterns.
- RDFS supplies an RDF data-modeling vocabulary.
- OWL can express logic-based knowledge that software may use for consistency checking and inference.
- SHACL describes constraints and validates RDF graphs against them.
- Apache Jena implements several capabilities relevant to this standards stack.
- FIBO is a concrete OWL ontology for financial-services concepts and relationships.
- Power BI can model table relationships and propagate filters according to defined relationship
  settings.
- The foundational RAG architecture combines retrieval from external memory with language
  generation.
- PROV-O supplies a standard vocabulary for representing provenance across entities, activities,
  and agents.
- RDF and OWL semantics do not generally treat an absent statement as false.
- SHACL conformance is relative to declared shapes and the data graph used in that validation run.
- GeoSPARQL and SensorThings are relevant utility integration references, but they solve different
  jobs and are not mandatory parts of every RDF architecture.
- R2RML defines a standard mapping from relational databases to RDF datasets.
- Stardog Virtual Graphs are one product implementation of query-time semantic mappings over
  external data.
- Databricks query federation is one product implementation of governed query-in-place for
  supported external databases.

## What the evidence does not support

- That RDF replaces relational, document, geospatial, time-series, or lakehouse platforms.
- That every artificial intelligence initiative needs RDF.
- That a knowledge graph automatically makes a language-model answer accurate, safe, current, or
  fully grounded.
- That inference and validation are the same operation.
- That current interest in Apache Jena, SHACL, or FIBO proves broad enterprise adoption.
- That FIBO is a utility ontology or should be imported into an OWOS utility model.
- That the supplied five-layer image defines a mandatory technical sequence.
- That the supplied image may be reproduced in a released course.
- That Power BI or relational systems contain no semantics.
- That RAG produces a different answer on every run.
- That every RDF query, reasoner, graph database, or graph-grounded agent is deterministic.
- That RDF alone supplies agent permissions, orchestration, validation, or safe execution.
- That a captured expert statement becomes approved enterprise knowledge without review.
- That labels alone establish identity.
- That a source system is authoritative for every statement because it is a system of record.
- That SHACL conformance establishes real-world truth, operational safety, or completeness.
- That an OWL inference is a prediction or language-model judgment.
- That absent graph data should automatically be treated as false.
- That a utility should build an enterprise knowledge graph before defining a bounded operational
  question and value measure.
- That every agentic application requires a formal ontology.
- That an ontology file, presentation, or glossary changes runtime behavior without implementation.
- That good context eliminates hallucination or makes a generative model perfectly deterministic.
- That “data stays put” means no indexes, caches, extracts, logs, results, or materialized hot paths
  exist.
- That virtualization is always cheaper, faster, safer, or more reliable than materialization.
- That embeddings or extracted entities are approved enterprise knowledge.
- That 80 percent of enterprise data is unstructured.
- That Stardog and Databricks are required, endorsed, or the only way to implement the architecture.
