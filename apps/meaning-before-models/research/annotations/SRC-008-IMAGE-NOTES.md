## Complete visual inventory

Its central visual is a five-layer stack:

1. RDF, described as the foundational triple-based data model.
2. RDFS, described as basic schema vocabulary.
3. SPARQL, described as the standard query language for RDF graphs.
4. OWL, described as a language for richer ontologies and inference.
5. SHACL, described as a way to enforce shapes and structural constraints.

## Course use decision

Use the conceptual ladder and triple explanation as research input. Do not reproduce or restyle the artwork as course artwork unless reuse permission is established.

Create an original OWOS interactive:

- begin with one relationship;
- let the learner build and correct triples;
- animate several triples becoming a graph;
- reveal the standards by job, not as an oversimplified claim that every implementation must run through a strict five-step stack;
- stop for a practical SPARQL relationship query;
- briefly preview OWL inference and SHACL validation as different capabilities.
