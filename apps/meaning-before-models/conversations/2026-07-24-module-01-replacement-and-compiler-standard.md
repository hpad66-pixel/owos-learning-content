# Module 01 Replacement and Compiler Standard

Date: 2026-07-24
Course: Meaning Before Models

## Hardeep direction

Hardeep asked for clarification about the unrelated AI Agents workspace change, explicitly directed
Codex to replace RDF Module 01 with the compiled structured lesson, and asked whether the compiler
would become the stable standard for every module and every existing course. He emphasized that the
system must not be casually changed and that course and module uniqueness must be verifiable.

## Recorded implementation decision

- Replace the curriculum and distributable Module 01 HTML with compiler output from the structured
  source package.
- Package all three real visual assets into the course distribution.
- Verify the distributed lesson, not only the local preview, at desktop, tablet, and phone widths.
- Version the stable compiler contract as `owos-course-compiler/1`.
- Require every governed course to carry an authoring migration manifest.
- Add a portfolio audit that distinguishes verified structured modules from legacy modules.
- Keep distinctiveness separate from compilation. The compiler provides deterministic, traceable
  delivery; the course identity, module fingerprint, storyboard, signature mechanism, visual
  manifest, adjacent-module comparison, and rendered review provide uniqueness.
- Do not alter or include the pre-existing AI Agents workspace-state change as part of this course
  replacement.

## Approval boundary

Hardeep approved replacement of Module 01 in the live-review course package. This approval does not
approve credentials, certification, operational authority, or the remaining seventeen module
conversions.
