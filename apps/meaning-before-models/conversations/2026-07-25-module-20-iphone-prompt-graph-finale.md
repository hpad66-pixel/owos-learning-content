# Module 20 iPhone Prompt-to-Graph Finale

## User direction

Add a final demonstration that simulates a real prompt on an iPhone, shows the prompt traversing the Knowledge Spine, reveals the graph and governed stages, and returns a beautiful deterministic answer.

The demonstration should make clear that learners can apply the same method to many more utility scenarios.

## Governed implementation

- Preserve the approved fifteen-step laboratory sequence.
- Add the prompt-to-graph demonstration as the culminating synthesis inside Step 15.
- Include wastewater, water, and stormwater prompts.
- Show intent and identity, graph traversal, evidence retrieval, validation, inference limits, runtime context, authority, and fixed answer rendering.
- Describe the answer as deterministic only under a frozen evidence snapshot, fixed query, fixed validation shapes, fixed inference rules, fixed policy, fixed permissions, and fixed response template.
- Do not claim that a generative model is inherently deterministic.
- Keep every tool call and utility record simulated.
- Do not publish or mark final release approved.
