# Meaning Before Models: RDF and Knowledge Graphs for Utilities

This is the governed course workspace for `owos-course-semantic-data-ai-001`.

## Current state

The five-part, eighteen-module curriculum is approved. Module 01 preserves the fifteen-minute RDF
primer, and Module 05 is the completed golden-lesson candidate. Both are working interactive lesson
candidates with recording scripts, deterministic assessments, professional work products,
responsive behavior, reduced-motion support, and repository-verifiable QA. The remaining curriculum
builds through identity, data models, taxonomies, ontology, semantic layers, SPARQL, reasoning,
validation, provenance, a running Knowledge Spine, federation, structured and unstructured
evidence, runtime AI context, BI and RAG comparisons, graph-grounded agents, and a utility pilot.
Nothing is released, credentialed, deployed, or published to the graph.

## Operating path

1. Preserve original sources in `research/originals/`.
2. Record sources, claims, permissions, limitations, and Hardeep's approved input.
3. Maintain the approved `SYLLABUS.md` and curriculum design matrix.
4. Review Module 05 and approve it before treating it as the production benchmark.
5. Run the Course Quality Contract before every release.
6. Publish only through a reviewed GitHub release and OWOS platform intake.
