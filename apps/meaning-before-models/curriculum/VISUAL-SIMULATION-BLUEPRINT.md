## Shared components required before production

Existing governed components cover network, layered stack, swimlane, timeline, comparison,
provenance, identity, failure propagation, decision trees, methods, artifact builders, and quiz
types.

The course likely requires these new shared components:

1. Five-Layer Artifact Sorter
2. Ontology-to-Operations Simulator
3. Semantic Mapping Bridge
4. Virtualize-or-Materialize Recommender
5. Structured-Unstructured Evidence Bridge
6. Context Packet Assembler
7. Fixed-versus-Variable Pipeline Lab
8. Governed Agent State Machine

Each new component must enter the shared library with keyboard, touch, mobile, reduced-motion,
screen-reader, live-feedback, gallery, and regression-test coverage before lesson use.
