# Curriculum

The blueprint package contains:

- `CURRICULUM-PACKAGE.md`: course thesis, recurring scenario, misconceptions, simulations, visuals,
  capstone, and success measures;
- `COURSE-DESIGN-MATRIX.md`: distinct learning experience for each module;
- `GLOSSARY.md`: plain-language definitions, pronunciation, utility examples, and boundaries;
- `INSTRUCTIONAL-VIEWS.md`: Foundation, Practitioner, and Leader treatments;
- `ASSESSMENT-BLUEPRINT.md`: module checks, final scenario, and scoring boundaries;
- `WORK-PRODUCTS.md`: Utility Semantic Starter Pack and capstone rubric;
- `METHODS-AND-FRAMEWORKS.md`: repeatable modeling, mapping, data-placement, context, and graph-fit
  methods;
- `VISUAL-SIMULATION-BLUEPRINT.md`: visual, interaction, component, and quiz plan for all modules;
- `FAQ-BLUEPRINT.md`: module-specific novice questions that final lessons must answer;
- `KNOWLEDGE-SPINE-AND-AI-CONTEXT-PACK.md`: detailed customer-exposure scenario, operational
  architecture, context packet, federation decisions, and failure simulations;
- `RDF-COMPARISON-AND-SIMULATION-PACK.md`: the detailed BI, RAG, graph, and agent scenario.

Lessons begin only after the curriculum blueprint and golden-lesson plan are approved. Every module
requires its own design brief before HTML or recording-script production.
