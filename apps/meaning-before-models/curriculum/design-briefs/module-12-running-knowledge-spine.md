| Question | Answer |

## Written-first review

- Approximate conversational teaching words: 2,300
- Worked utility example and marker: P-104 service-impact question; `data-worked-example`
- Misconception addressed: Knowledge spine means copy everything into one graph.
- Boundary or non-example: Virtualization is not always preferable; materialization can be justified.
- Component debriefs: Every architecture graphic includes a conclusion.
- What remains if every video and animation is removed: Full architecture, agent connection, operating model, exercises, brief, FAQs.

## Visual pacing review

- Longest run of consecutive full prose blocks: Two paragraphs.
- Visual, interaction, worked example, or callout used to break each dense section: Bridge, stack, estate, answer path, switchboard, RACI.
- Any uninterrupted prose exception and reason: Operating definition groups essential terms.
- Editorial illustration reading guide and learner conclusion, when used: Bridge wall explained by opening coach.
- Dark-surface contrast plan: Spine core and answer preview use explicit light text.
