## Observation tasks

Without coaching, ask the learner to:

1. Explain the difference between a data model and an ontology.
2. Explain what a taxonomy adds.
3. Point to the layer that connects shared meaning to real utility records.
4. Explain what belongs in AI context for the pressure-event task.
5. Describe what a context engine does.
6. Diagnose why an ontology in a slide deck does not ground an agent.
7. Build and explain the Five-Layer Meaning Map.

## Comprehension questions

1. What was the clearest moment?
2. Where did the terms begin to blur?
3. Which visual helped most?
4. Which interaction felt like busywork?
5. What would you explain to a colleague tomorrow?

## Pilot threshold

The candidate is ready for benchmark approval only when representative nontechnical learners can
distinguish all five layers, identify the human authority boundary, and complete the work product
without instructor rescue. Record failures as design corrections, not learner failures.
