# Academy Workflow and Pathway Simplification Direction

Date: 2026-08-06
Source: Hardeep Anand, Codex conversation
Destination: AI Master Class pathway blueprint and the separate APAS Academy Studio application
Status: Approved for planning and implementation

## Hardeep's direction

Complete a thorough QA and quality-control review of the Academy. The application became cluttered
because it was built incrementally. Reorganize the team experience in chronological order:

1. master curriculum;
2. research;
3. assignments and ownership;
4. module production by different people;
5. upload and review;
6. feedback, revision, quality control, publication, and automation.

Make the full team path easy to understand. Team members must be able to upload their work. Hardeep
must be able to review it, return it, and preserve the revision and person responsible for the
change.

Reduce the number of learner tracks. Create one all-encompassing foundation for everyone, including
Chief AI Officers, then use a smaller number of clear role applications. Every role application must
open into a complete, beautifully designed, market-ready landing-page preview with audience,
problems, objectives, outcomes, graphics, calls to action, and signup. The application must remain
state of the art while showing the difference between internal previews, approved curriculum,
connected systems, and live public claims.

Write a detailed plan file before implementation, then implement the plan and publish the validated
private Academy to the agreed subdomain.

## Preserved boundary

This direction approves planning, blueprint simplification, application implementation, testing, and
private deployment. It does not approve public marketing claims, pricing, credential issuance,
finished learner-facing lessons, Articulate release, or a public enrollment launch.
