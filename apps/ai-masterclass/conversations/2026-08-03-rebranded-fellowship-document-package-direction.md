# Rebranded Fellowship document package direction

## Hardeep's direction

The final downloadable documents must use the approved working program name, **One Water AI
Executive Fellowship**. The revised set must bring the full program into one clear HTML document and
one printable PDF, with the supporting curriculum and Fieldbook available together.

## Implemented interpretation

- Build one self-contained HTML program book and one synchronized PDF program book.
- Include the value proposition, intended participants, 24-week design, all eight courses, all 64
  modules, capstone requirements, completion evidence, Fieldbook relationship, research and citation
  controls, graphics process, and Articulate, LearnWorlds, and OWOS delivery architecture.
- Package the program book, curriculum PDF, Fieldbook PDF, and reusable module template in one ZIP.
- State the release boundary plainly. The current program architecture is complete. The 64
  learner-facing Articulate modules are not all complete.
- Preserve the older 686-page One Water AI Master Class compilation as a legacy source library. Do
  not relabel it as current Fellowship instruction.

## Naming control

Current program: `One Water AI Executive Fellowship`

Legacy source library: `One Water AI Master Class`

The two names must not be presented as interchangeable.
