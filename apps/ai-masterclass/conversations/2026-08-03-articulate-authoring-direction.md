# Direction: Articulate-Ready AI Master Class Authoring

Date: 2026-08-03

Hardeep directed the team to create a governed course-authoring structure for the AI Master Class.
Research may come from videos, LinkedIn, Perplexity, white papers, PDFs, and Hardeep's annotations.
The resulting course package should use Articulate AI consistently, with a version-controlled
Markdown source package that Articulate can transform into a responsive course draft.

Hardeep asked for the first local course repository structure and asked whether a future 64-module
course would have a consistent file structure for all modules.

Decision recorded: one course workspace contains the shared research and course controls. Each
approved module receives one standard module folder. Do not create speculative empty folders for
all future modules.
