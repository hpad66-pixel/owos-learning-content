# Articulate Authoring Runbook

## Purpose

Use Articulate AI to accelerate a governed course package. Do not make Articulate a second source
of truth or a black box that creates untraceable learning content.

## Before using Articulate

Confirm that the course package has:

- registered originals and permissions;
- source and claims review appropriate to the module;
- a completed module design brief;
- a source manuscript with instructor explanations;
- visual, interaction, assessment, FAQ, and recording-script plans; and
- an approval record authorizing an Articulate draft.

The approved manuscript begins from
`../research/MODULE-RESEARCH-AND-VISUAL-BRIEF-TEMPLATE.md`. It must contain the module value
proposition, verified claims with direct locators, complete instructor teaching, utility examples,
graphic descriptions, reading guides, learner conclusions, assessments, FAQ, and evidence boundary.

Perplexity may help discover source leads. Do not copy its answer into Articulate as verified course
content. Open the original source, record it in the source register, verify the claim and locator,
and update the claims register first.

## In Rise or Storyline

1. Create the course in the correct team folder and name it with the stable course and module ID.
2. Upload the approved Articulate import package or copy its controlled content.
3. Ask AI Assistant to preserve the specified sequence and create only the requested blocks.
4. Replace any invented factual statement, generic image, or unsupported question before review.
5. Add approved branded diagrams, captions, alternative text, and recording assets.
6. Test every interaction, feedback path, keyboard path, mobile state, and reduced-motion view.
7. Record the Articulate project URL, revision date, reviewer, and export type in the module's
   `production-status.md` and `release/` record.

## After Articulate

Bring the reviewed changes back to this repository. Update the master manuscript and import package
when the teaching changes. Do not leave a meaningful improvement only inside Articulate.

## Export and delivery

Export the approved package in the delivery format selected for LearnWorlds. Record the exact
export, version, checksum, test result, and destination. LearnWorlds hosts and sells the learner
experience. It does not replace the course's source, evidence, or QA record.
