# Staff Direction for M41: Agents, Agentic Nests, and Orchestration

## Your assignment

Teach agents as bounded work systems with goals, environment, observations, actions, plans, tools, state, evidence, evaluation, handoffs, coordination, interaction, stop conditions, recovery, and accountable humans.

Open with this situation: Three agents produce separate recommendations, but they use different source versions and no person owns disagreement or the final decision.

Ask the learner to decide before teaching begins: **Choose between a fixed workflow, one agent, or multiple specialists, then define the planning pattern, tool and state boundary, handoff, disagreement, recovery, escalation, and human-decision contract.**

Use this analogy once as the front door, then return to the utility work: A staffed incident room works because roles, evidence, handoffs, command, and the decision log are explicit. More people without coordination create noise.

The learner must leave with a saved **utility agent architecture, coordination, and recovery contract**. If the module does not produce that
record and evidence, the module is not complete.

1. Explain Agents, Agentic Nests, and Orchestration in plain English and connect it to a real water, wastewater, stormwater, or One Water decision.
2. Distinguish workflow, agent, goal, environment, observation, action, plan, Reason and Act, tool, state, specialist, orchestrator, shared state, handoff, evaluation, retry, conflict, deadlock, recovery, escalation, and stop without using one term to hide several different jobs.
3. Analyze the module situation, identify missing evidence, and name the professional consequence of a weak decision.
4. Compare how the same question changes across drinking water, wastewater, stormwater, administration, engineering, finance, technology, and public leadership.
5. Evaluate sources, assumptions, limitations, permissions, and human authority using this boundary: Do not imply that planning text, multiple agents, perceived agency, or tool access creates independent truth, professional judgment, or operating authority. Preserve sources, permissions, cost limits, dissent, and human decision rights.
6. Create a usable utility agent architecture, coordination, and recovery contract with evidence, roles, limits, review steps, and the next accountable action.
7. Defend the recommendation to Foundation, Practitioner, and Leader audiences while keeping disagreement and uncertainty visible.

### `M41.CE01` Agents, goals, environments, and perceived agency

Give learners a precise model for what an agent observes, what it may do, what goal it is pursuing, what environment it operates in, and why people can perceive more intelligence or authority than the system has.

- Required work product: **utility agent environment and authority specification**
- Secondary module connections: M03, M06, M10
- Learning objectives:
  - Distinguish a model response, deterministic workflow, bounded agent, and multi-agent work system.
  - Specify a task using goal, performance measure, environment, observations, allowed actions, state, and stop conditions.
  - Compare predictable, uncertain, observable, partially observable, static, and changing environments.
  - Identify language and interface choices that cause people to overstate agency, understanding, or authority.
  - Create a utility agent environment and authority specification.
- Assessment evidence:
  - system classification
  - environment analysis
  - agency-language correction
  - completed agent specification
- Evidence boundary: The academic agent model is a design lens. It does not grant an artificial intelligence system legal, professional, or operating authority.

### `M41.CE02` Planning, Reason and Act, reflection, and agentic retrieval

Compare fixed workflows with planning patterns that alternate reasoning, tool use, observation, evaluation, revision, and stop. Make observable evidence and control more important than hidden reasoning text.

- Required work product: **governed agent plan and trace**
- Secondary module connections: M07, M14, M33
- Learning objectives:
  - Compare fixed workflow, plan-and-execute, Reason and Act, reflection, and agentic retrieval patterns.
  - Trace the observable goal, plan, action, tool result, evidence, evaluation, adjustment, and stop for one task.
  - Choose the least complicated planning pattern that can satisfy the utility task and consequence boundary.
  - Identify endless-loop, tool-selection, stale-evidence, plan-drift, and false-completion failures.
  - Create and test a governed agent plan and trace.
- Assessment evidence:
  - pattern comparison
  - trace ordering
  - failure injection and recovery
  - completed plan and trace
- Evidence boundary: Do not expose private hidden reasoning or treat a generated reasoning narrative as proof. Evaluate observable actions, sources, tool results, and outcomes.

### `M41.CE03` Multi-agent coordination, conflict, cost, and failure

Teach multiple agents as a coordinated work system with explicit roles, communication, shared state, arbitration, evidence, cost, and accountable human decision. More agents can create more failure as easily as more capability.

- Required work product: **multi-agent coordination and recovery contract**
- Secondary module connections: M20, M24, M26, M31, M51
- Learning objectives:
  - Choose among one workflow, one agent, and multiple specialist agents for a bounded utility task.
  - Design roles, messages, shared state, source versions, handoffs, arbitration, escalation, and final human authority.
  - Identify duplication, disagreement, stale state, deadlock, cascading error, excessive cost, and false consensus.
  - Use basic cooperation, incentive, and conflict reasoning without implying that agents are independent professionals.
  - Create and test a multi-agent coordination and recovery contract.
- Assessment evidence:
  - architecture choice
  - handoff and state simulation
  - failure-propagation diagnosis
  - completed coordination contract
- Evidence boundary: Multiple agents do not create independent truth, professional judgment, or legal authority. Preserve source versions, permissions, cost limits, dissent, and human decision rights.
