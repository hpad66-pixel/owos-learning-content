# Module M00: Orientation, Setup, and Your Learning Path

This folder is the first complete curriculum-scrub and staff-direction prototype for the legacy
Applied Intelligence source curriculum.

The prototype does not delete, silently relocate, or approve existing curriculum material. It gives
staff a clear learning job, observable outcomes, scope boundaries, placement recommendations,
research instructions, and review criteria before learner-facing production begins.

| File | Purpose |
| --- | --- |
| `STAFF-DIRECTION.md` | Direct assignment for research, curriculum, writing, graphics, assessment, Articulate, marketing, and quality-control staff |
| `AI-RESEARCH-AND-PRODUCTION-PROMPT.md` | Governed prompt that requires a goal and plan before drafting |
| `CONTENT-PLACEMENT-REGISTER.json` | Stable block-level placement recommendations that preserve all current and proposed material |
| `production-status.md` | Visible approval and production boundary |

The governed design brief is
`curriculum/design-briefs/module-00-orientation-setup-learning-path.md`.
