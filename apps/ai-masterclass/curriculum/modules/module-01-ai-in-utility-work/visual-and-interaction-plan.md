# Module 01 Visual and Interaction Plan

| Component | Teaching job | Learner instruction | Accessibility and mobile behavior |
| --- | --- | --- | --- |
| Accountability decision map | Show where support ends and accountable action begins | Read left to right, then identify the review and decision owner | SVG or semantic process list with text alternative. Stack vertically on phone. |
| Responsibility sorting | Repair the misconception that useful output equals delegated authority | Place each action in the best responsibility column, then read the explanation | Keyboard-operable controls with a non-drag alternative. Stack columns on phone. |
| Context comparison | Show why approved information changes answer quality | Compare the source boundary and explain which answer you would trust more and why | Two labeled cards, never color alone. Stack on phone. |
| Handoff sequence | Show that a governed workflow is a visible sequence | Step through the handoff and identify where you would escalate | Numbered static equivalent for reduced motion. |
| Boundary card | Convert concept into a practical decision aid | Complete each field for one low-risk task | Downloadable and form-accessible version. |

No decorative AI imagery satisfies this plan. Every graphic must teach a relationship, boundary, or
sequence and must be explained in instructor text.
