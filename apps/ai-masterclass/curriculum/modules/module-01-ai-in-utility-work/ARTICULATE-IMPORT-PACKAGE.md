# Articulate Import Package: Module 01

## Use

This is the controlled prompt and content specification for Articulate Rise AI or Storyline. Upload
or paste it only after the source map and claims register show approved evidence. Ask Articulate AI
to retain the headings and learning sequence. Do not ask it to invent sources, operating policy,
or factual claims.

## Articulate AI instruction

Create a responsive learning module for water, wastewater, and stormwater professionals. Use a
calm, plain-English instructor voice. Do not use marketing language, unexplained technical terms,
or unsupported claims. Keep the learner reading surface uncluttered. Use accessible headings,
descriptive alternative text, visible focus treatment, and a reduced-motion equivalent for any
animated sequence.

Build the following in order:

1. Opening decision scenario.
2. Two instructor paragraphs on assistance versus accountability.
3. Labeled decision map with a reading guide.
4. Three-column responsibility sorting interaction with explanatory feedback.
5. Two instructor paragraphs on approved context and answer limits.
6. Before-and-after context comparison.
7. Numbered handoff sequence with a static reduced-motion form.
8. AI use-case boundary card activity.
9. Final applied knowledge check with retry and rationale.
10. Six-question FAQ using accessible accordions.
11. Source and limitation area reserved for approved citations.

## Required blocks and interaction mapping

| Teaching purpose | Recommended Articulate form | Acceptance condition |
| --- | --- | --- |
| Opening choice | scenario or decision block | learner chooses before explanation |
| Accountability map | labeled graphic or process block | every step has explanatory text |
| Responsibility sorting | sorting activity | feedback explains the utility consequence |
| Context comparison | comparison or tabs block | the source boundary is visually clear |
| Handoff | timeline or process block | full sequence works without animation |
| Boundary card | downloadable worksheet or Storyline form | learner can save or download it |
| Knowledge checks | varied Rise questions or Storyline checks | feedback and retry are enabled |
| FAQ | accordion block | one question and answer per item |

## Media policy

Use only approved branded diagrams or properly licensed media. Do not use generic robot imagery.
Every image needs alternative text and a plain-English reading guide in adjacent course text.

## Publish boundary

Export only after human review. The Articulate output must be reviewed against this package and the
repository version before it is sent to LearnWorlds or OWOS.
