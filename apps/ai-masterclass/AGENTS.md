# AI Master Class Instructions

Use the `continue-owos-course` skill for every material task in this folder.

This workspace is the master source for the AI Master Class series. It coordinates course assets
that may be assembled in Articulate and delivered through LearnWorlds, but neither external tool
replaces this repository as the governed authoring record.

## Operating rule

Before building a module, read `COURSE-BRIEF.md`, `STATE.md`, `APPROVALS.md`, `course.yaml`, and
`SYLLABUS.md`, then follow the shared OWOS Course Production Contract.

For each module, preserve original research, record source and claim boundaries, write a module
design brief, update the course design matrix, build the source manuscript, create its Articulate
import package, and complete QA before proposing release.

## Articulate rule

Articulate AI may draft an outline, blocks, images, knowledge checks, or narration from an approved
import package. It may not decide course facts, claim support, utility applicability, audience
boundaries, assessment logic, or release status. The approved source manuscript is copied or
uploaded into Articulate only after those decisions are present here.

## Module folder contract

Every approved module folder follows this shape:

```text
module-NN-slug/
  README.md
  MODULE-MANUSCRIPT.md
  ARTICULATE-IMPORT-PACKAGE.md
  source-map.md
  visual-and-interaction-plan.md
  assessment-plan.md
  faq.md
  production-status.md
```

The module's design brief lives in `curriculum/design-briefs/`, its recording script lives in
`curriculum/scripts/`, and its QA report lives in `qa/`. This keeps the course-wide catalogues
readable without duplicating control records.

No module is public, graph-promoted, credential-bearing, or LearnWorlds-ready merely because an
Articulate draft exists.
