## Foundational AI agent course

Build this as a foundational course for water, wastewater, and stormwater professionals. Teach what an agent is, what precedes it, how it differs from a chatbot and other adjacent artificial-intelligence concepts, and how an agent differs from broader agentic behavior or an agentic system.

Create aha moments through purposeful animations, simulations, streaming, orchestration, agent handoffs, guardrails, agent types, and credible utility applications. Separate future courses will cover retrieval-augmented generation, chatbots, and other terms in greater depth.
