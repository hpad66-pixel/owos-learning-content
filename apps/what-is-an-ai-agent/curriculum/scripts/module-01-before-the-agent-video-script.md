## Spoken words

Before we talk about agents, we need to clear up the terms around them. Imagine that a utility manager asks, "Which lift stations should we inspect first after this rainfall event?" Several systems could respond, but they would not all be doing the same work.

A model can generate an answer from the information placed in its prompt. A chatbot gives you a conversational way to interact with a model or another system. Retrieval means the system searches approved material and brings relevant records into the current task. A fixed workflow follows steps that were defined in advance. An agent works toward a goal, uses approved tools, observes the result, and selects a permitted next step.

[Show the five comparison cards one at a time.]

As you compare the cards, do not ask only whether the screen looks intelligent. Ask what control is actually present. Can the system choose a next step? Can it use a tool? Does it observe what happened? Can it stop or ask a person for help? Those questions tell you more than the product label.

In this lesson, you will classify utility examples. You will also build an AI terms field card that you can use in meetings. The field card should let you explain each term in one plain sentence and give one utility example.

The main takeaway is simple. Conversation is not the same as agency. Access to documents is not the same as agency. Automation is not the same as agency. Once you can see those differences, you can ask better questions about cost, risk, evidence, and accountability.
