# Course Recording Scripts

These scripts help Hardeep record instructor videos for the course. They are source artifacts, not published video files.

## Recording package

- `COURSE-OVERVIEW-VIDEO-SCRIPT.md` introduces all eight lessons in one recording.
- Each `module-XX` file supports one lesson recording.

## Script rules

- Text under **Spoken words** is written to be read aloud and adapted naturally.
- Text in brackets is a visual or editing direction. It is not spoken.
- Technical terms are explained before they are shortened or reused.
- Every script includes a utility situation, the learner action, the work product, and the transition to the next lesson.
- Claims must remain inside the course evidence boundary.
- Update the overview script whenever the curriculum sequence changes.
