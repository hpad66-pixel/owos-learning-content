# Foundational AI Agent Glossary

These definitions seed the course's accessible tooltip system. Each rendered lesson explains the term in the teaching text before using the tooltip as reinforcement.

| Term | Plain-English definition |
| --- | --- |
| Agent | A bounded software system that can choose parts of its process and use approved tools to work toward a goal. |
| Agentic | Describes goal-directed behavior in which a system can adapt parts of how it performs a task. |
| Agentic system | A broader system that may combine fixed workflows, one or more agents, tools, memory, evaluation, and human checkpoints. |
| Artificial intelligence model | Software trained to recognize patterns and produce an output from an input. The model is one part of an agent. |
| Large language model | A model trained on large amounts of text so it can interpret and generate language. |
| Chatbot | A conversational interface that exchanges messages with a person. It may or may not contain an agent. |
| Retrieval-augmented generation | A method that finds selected external information and provides it to a model before the model produces an answer. |
| Prompt | The instruction or information given to a model for the current request. |
| Instruction | A durable rule telling the agent how to behave, what process to follow, or when to stop. |
| Tool | An approved function or connected system the agent can use to retrieve information or take an action. |
| Application programming interface | A defined way for one software system to request data or actions from another system. |
| Memory | Information retained for later use across a task or conversation. |
| State | The current recorded condition of the task, including what has happened and what remains. |
| Workflow | A sequence of steps used to complete a job. In a deterministic workflow, software code controls the route. |
| Orchestration | The coordination of tasks, agents, tools, handoffs, and completion rules. |
| Handoff | The transfer of work, context, evidence, and authority from one agent or person to another. |
| Guardrail | A boundary that checks, blocks, pauses, redirects, or escalates behavior. |
| Human-in-the-loop | A design in which a person reviews, approves, corrects, or takes over part of the work. |
| Evaluation | A defined test used to judge whether an agent's process or result is acceptable. |
| Hallucination | An unsupported or incorrect output presented as if it were reliable. |
| Prompt injection | Content designed to manipulate a model into ignoring instructions or taking an unintended action. |
| Streaming | Showing events or partial output as work progresses instead of waiting for the entire task to finish. |
| Multi-agent system | A system in which several agents have different responsibilities and coordinate toward a shared result. |
| Deterministic | Produces the same defined result when the same rules and inputs apply. |
| Probabilistic | Selects among possible outputs based on learned patterns, so results may vary. |
