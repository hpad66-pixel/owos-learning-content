A pump alarm is visible. The maintenance history is not.

The agent may retrieve approved records and prepare a recommendation. It may not change the control system, certify the asset condition, or conceal missing evidence.

Instructor explanation

An agent loop is a controlled cycle. The system begins with a goal, selects a next step, uses a tool, observes what happened, evaluates the result, and either stops, adjusts, retries, or asks a person to decide.

The event stream shows observable work. It does not expose private hidden model reasoning. You can inspect the goal, tool, source, permission, result, evaluation, and escalation.

Tool event

Read-only connectors are authorized.

The agent may search and read. It cannot acknowledge an alarm, change a set point, or close a work order.

Observation event

Evaluation event

The evidence is useful but incomplete.

The packet can support a maintenance recommendation, not an asset-condition certification.

Escalation event

The supervisor receives the evidence and the limitation.

The loop stops with a named person, a clear question, and a traceable record.
