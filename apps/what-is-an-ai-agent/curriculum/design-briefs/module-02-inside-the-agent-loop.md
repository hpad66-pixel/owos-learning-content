# Module 2 Design Brief: Inside the Agent Loop

Status: curriculum build

## Learning job

A lift-station maintenance packet is incomplete. The learner watches a bounded agent move from a goal through planning, tool selection, evidence retrieval, action, observation, evaluation, adjustment, and escalation.

## Outcomes

The learner can explain the operating loop, distinguish visible system events from hidden model processing, interpret an event stream, identify a stop condition, and diagnose a loop that should escalate.

## Experience design

| Element | Design |
| --- | --- |
| Narrative | Step-through task execution |
| Mental model | Goal-to-result operating loop |
| Visuals | Interactive cycle, event timeline, tool map, progress ring, retry gauge |
| Interaction 1 | Back, Step, Play, Pause, and Reset loop simulator |
| Interaction 2 | Event-stream inspector showing task, tool, source, permission, evaluation, retry, and handoff events |
| Quiz mix | Ordering, multiple choice, estimate |
| Work product | Agent Loop Trace |
| Capstone | Draw the proposed goal-to-result loop |
| Graph | Active loop step highlights its concepts, controls, and evidence relationships |
| Mobile | Simulator controls remain fixed below a single active-step card |

## Streaming boundary

The lesson streams observable events and partial results. It does not claim to reveal private hidden reasoning. Learners see what the system did, what evidence it used, what tool it called, and what decision boundary applied.

## Completion evidence

Full loop replayed, failed loop repaired, event interpretation passed, and capstone loop saved.
