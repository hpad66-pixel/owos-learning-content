# Module 1 Design Brief: Before the Agent

Status: learner-facing master-class candidate built

## Learning job

Open with one real question: “Which maintenance work orders need attention before tomorrow's shift?” Show five responses produced by a basic model, a chatbot, retrieval-supported generation, a fixed workflow, and a bounded agent. The learner decides which system is actually doing what.

## Outcomes

The learner can distinguish a model, prompt, chatbot, retrieval, deterministic workflow, agent, and multi-agent system; explain why conversation does not equal agency; and choose the least complicated system appropriate to a task.

## Experience design

| Element | Design |
| --- | --- |
| Narrative | Progressive comparison of the same utility question |
| Mental model | Capability ladder from answer generation to bounded action |
| Visuals | Layered stack, comparison table, autonomy spectrum, term cards |
| Interaction 1 | Classify ten utility examples by system type |
| Interaction 2 | Add retrieval, tools, state, and permissions to watch the system category change |
| Quiz mix | Classify, matching, reflection |
| Work product | AI Terms Field Card |
| Capstone | State the utility problem and classify the current process |
| Graph | Terms connect to capabilities, sources, tools, and roles in a same-page drawer |
| Mobile | Five systems become a swipeable comparison with a persistent plain-English definition |

## Tooltip focus

Model, prompt, chatbot, retrieval-augmented generation, deterministic workflow, agent, multi-agent system, agentic, tool, and state.

## Completion evidence

Classifier completed, capability-builder completed, knowledge check passed, and capstone problem saved.
