# Build Curriculum Authorization

Date: 2026-07-22

Contributor: Hardeep Anand

## Direction

Build the complete curriculum for the foundational course on AI agents for water, wastewater, and stormwater utility professionals.

The curriculum must:

- serve a novice utility learner;
- explain technical terms in simple English;
- use tooltips to support understanding;
- make the anatomy of an agent visible and interactive;
- include animations, simulations, decisions, orchestration, handoffs, and guardrails;
- connect concepts to credible utility situations;
- lead to an applied capstone and a practical work product;
- preserve the governed golden-lesson approval gate before bulk learner-facing production.

## Approval boundary

This direction authorizes the complete curriculum source package and module design briefs. It does not approve the golden lesson, the working title, credential claims, graph publication, or public course release.
