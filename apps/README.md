# Learning applications

One folder per governed course or learning product. Each application reuses the shared foundation in
`../core/`, so the learner experience remains consistent.

- **`project-management/`** the Project Management masterclass (course chrome, chapters, playbook,
  starter kit). Built.
- **`data-ai-governance/`** the Data Before AI Master Class. Its complete utility-deployable syllabus,
  60-criterion coverage, course record, role pathways, studios, and capstone are ready for owner lock.
- Additional master classes, technical courses, cohort programs, and graph-connected learning
  products can be added here as they are governed and approved.

To start a new app: make a folder here, copy `../core/components/module-template.html`, point at
`../core/brand` and `../core/standards`, and follow the build order in
`../core/standards/WRITING-STANDARD.md`.
