# Data and Artificial Intelligence Governance for Utilities

This application contains the governed curriculum source for the One Water Operating System (OWOS)
Master Class **Data Before AI: Data and Artificial Intelligence Governance for Utilities**.

## Start here

- [Complete syllabus](curriculum/SYLLABUS.md)
- [Machine-readable course record](course.yaml)
- [Course-to-Learn architecture](../../docs/OWOS-COURSE-TO-LEARN-ARCHITECTURE.md)

## Source authority

The course is derived from **Data Ready Before AI Ready, Version 2.3** in the private
[`hpad66-pixel/utility-data-ai-governance`](https://github.com/hpad66-pixel/utility-data-ai-governance)
repository. That repository remains authoritative for the method, 60 assessment criteria, 217-source
register, controlled figures, Quality Assurance and Quality Control evidence, and release gates.

This folder is authoritative for what the course teaches, asks the learner to do, and assesses. It
must not silently redefine the controlled method.

## Current state

The complete syllabus and coverage design are governed. Chapter 00 is a released interactive lesson
with a Deployment Studio, Launch Pack tracker, checks, and an OWOS Learn completion event. The other
24 chapter destinations preserve the approved syllabus structure while their lesson bodies remain in
development. Course-completion credential language and scored assessments remain proposed until their
separate review and pilot gates pass.

## Build rule

Read the syllabus first. Then follow:

1. `../../core/standards/WRITING-STANDARD.md`
2. `../../core/standards/VISUAL-ARSENAL.md`
3. `../../core/components/component-gallery.html`
4. `../../core/components/quiz-gallery.html`
5. `../../core/components/module-template.html`

Course content stays here. OWOS.AI receives governed build outputs and records learner state through
Supabase. The Knowledge Graph connects course and lesson identifiers to sources, concepts,
contributors, roles, and competencies.
