# OWOS Module Design Brief

## Identity

| Field | Decision |
| --- | --- |
| Course and module ID | `owos-master-data-governance-001`, `dga001:20` |
| Working title | A maturity number without evidence is decoration |
| Learner roles | Assessment sponsors, facilitators, utility practitioners, reviewers, leaders |
| Competencies | Frame, gather, triangulate, score, limit, and act on assessment evidence |

## Learning job

The learner must replace a workshop maturity decimal with a traceable capability conclusion, confidence statement, limitation, finding, and next action.

## Instructor explanation plan

| Component | Instructor job | Debrief |
| --- | --- | --- |
| Fieldwork stepper | Preserve a chain from scope to action | A conclusion should be reproducible |
| Confidence radar | Separate evidence dimensions from maturity level | Do not average away missing evidence |
| Calibration check | Write a useful but bounded report line | False precision and total silence are both errors |

## Visual pacing review

- Lined fieldbook panels create a distinct assessment-notebook experience.
- The six-step horizontal sequence, worked metadata sample, radar profile, and calibration console alternate prose and action.
- Sticky-note findings close the applied judgment before the artifact.
- Mobile treatment stacks inputs and findings; reduced motion removes decorative rotation.
