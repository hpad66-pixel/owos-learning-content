# Module Design Brief: Module 12 Teams, Stakeholders, and Communication

## Identity

| Field | Decision |
| --- | --- |
| Course and module ID | `owos-master-project-delivery-001` / `pm-12-teams-stakeholders-communication` |
| Working title | The team, the stakeholders, and the message |
| Learner roles | Project manager, sponsor, operator, engineer, superintendent, public-information lead |
| Competencies | Clarify responsibility, select engagement strategy, control project communication |

## Learning job

| Question | Answer |
| --- | --- |
| What consequential situation opens the lesson? | A technically correct project can lose support because roles and messages are unclear. |
| What must the learner decide before teaching begins? | Who owns the decision and how an affected stakeholder should be engaged. |
| What professional consequence makes this matter? | An unresolved role or surprise can stop work, damage trust, or escalate to council and regulators. |
| What should the learner be able to do afterward? | Conduct a responsibility conversation and write an executable stakeholder strategy. |
| What usable work product will the learner create? | Stakeholder engagement brief. |
| What evidence is required for completion? | Opening condition, role conversation, completed brief, final brief gate. |

| Major component | What the learner sees | What the learner does | What to notice | Utility meaning | Debrief needed |

## Written-first review

- Approximate conversational teaching words: More than 1,500.
- Worked utility example and marker: Millpond school entrance and four-hour shutdown.
- Misconception addressed: More approvers and more messages always reduce risk.
- Boundary or non-example: A project website alone is not direct time-critical notice.
- Component debriefs: Visible after role conversation, map, network, strategy decision, and artifact.
- What remains if every video and animation is removed: Complete role teaching, scenarios, strategies, work product, FAQ, evidence, and completion controls.

## Visual pacing review

- Longest run of consecutive full prose blocks: Two.
- Visual, interaction, worked example, or callout used to break each dense section: Conversation, map, strategy decision, network, communication set, artifact.
- Any uninterrupted prose exception and reason: None.
- Editorial illustration reading guide and learner conclusion, when used: Not applicable.
- Dark-surface contrast plan: Drawer header uses explicit white text.
