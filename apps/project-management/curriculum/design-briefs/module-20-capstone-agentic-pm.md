# Module Design Brief: Module 20 Capstone Agentic Project Management

## Identity

| Field | Decision |
| --- | --- |
| Course and module ID | `owos-master-project-delivery-001` / `pm-20-capstone-agentic-pm` |
| Working title | Run the whole job: you decide, Droobi does |
| Learner roles | Project manager, sponsor, engineer, operator, finance lead, accountable agent user |
| Competencies | Frame the problem, integrate evidence, compare options, define delegation, defend action |
| Controlled sources | Approved project, engineering, operating, financial, contractual, regulatory, security, and governance evidence |
| Evidence boundary | Cypress Creek is instructional and no agent receives autonomous project authority. |

## Learning job

| Question | Answer |
| --- | --- |
| Consequential situation | Cypress Creek has overflow, growth, failing assets, deadline pressure, and incomplete information. |
| Initial decision | What problem to solve and which work may be delegated. |
| Professional consequence | Wrong framing or delegated accountability can produce confident, fast, expensive failure. |
| Post-lesson capability | Assemble and defend a decision with evidence, authority, human boundary, action, and remaining risk. |
| Work product | Capstone decision pack. |
| Completion evidence | Opening, agent gate, decision pack, final review. |

## Written-first review

- Approximate teaching words: More than 3,200.
- Worked example: Cypress Creek from problem through red status and delegation.
- Misconception: Better tooling repairs wrong framing, or citation transfers accountability.
- Boundary: No autonomous operation or decision authority.
- Debriefs: Present.
- Without media: Complete capstone teaching, decisions, pack, FAQ, and boundary.

## Visual pacing review

- Longest prose run: Two.
- Breaks: Five decisions, agent sorter, gate path, comparison, boundary gate, pack.
- Exception: None.
- Illustration: Not applicable.
- Contrast: Explicit light text on dark surfaces.
